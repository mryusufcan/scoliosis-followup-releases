# Scoliosis Follow-Up GitHub Pages

Bu klasör doğrudan GitHub Pages için hazırlanmıştır.

## Dosyalar
- `index.html` — tanıtım + kapsamlı kullanım rehberi
- `assets/goruntuleyici.png`
- `assets/skolyoz-takip.png`
- `assets/dicom-birlestirme.png`

## Yayınlama
1. GitHub'da sitenin yayınlanacağı repository'ye bu klasörün içeriğini yükleyin.
2. Repository → Settings → Pages bölümüne girin.
3. Source olarak **Deploy from a branch** seçin.
4. Branch olarak `main`, klasör olarak `/(root)` seçip Save'e basın.
5. GitHub Pages adresi oluşturulduğunda `index.html` otomatik açılır.

Not: İndirme/GitHub butonları özellikle eklenmedi. Release ve repository adresleri netleştirildiğinde index.html'e eklenebilir.

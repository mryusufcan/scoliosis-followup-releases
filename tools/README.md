# Geri dönüş noktaları

PowerShell dosyalarını çift tıklamak yerine aşağıdaki `.cmd` dosyalarını kullanın:

- `YeniGeriDonusNoktasi.cmd` — mevcut çalışan kod için yeni kayıt oluşturur.
- `GeriDonusNoktalariniListele.cmd` — kayıtları listeler; pencere açık kalır.
- `GeriYukle.cmd` — kayıtları listeler ve seçtiğiniz etikete geri döner.

Geri yüklemeden önce uygulamayı kapatın. Hasta verileri, DICOM görüntüleri ve yerel veritabanı geri yükleme işleminden etkilenmez.

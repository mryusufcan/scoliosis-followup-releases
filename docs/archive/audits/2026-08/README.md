# Ağustos 2026 Audit Arşivi

Bu klasördeki JSON raporları proje boyutu, release, restore point, quarantine, model duplicate ve son çalışma ağacı denetimlerinin tarihsel kayıtlarıdır. Normal uygulama açılışı için gerekli değildir; karar geçmişi ve temizlik doğrulaması amacıyla korunur.

Güncel kullanıcı ve release belgeleri üst `docs` klasöründe bırakılır. Yeni denetimler mümkün olduğunca tarih damgalı dosya adıyla bu klasör altında saklanmalıdır.

Arşivlenen dosyalarda hasta görüntüsü veya SQLite çalışma verisi bulunmaması hedeflenmiştir. Paylaşım öncesi güvenlik ve kişisel veri denetimi ayrıca yapılmalıdır.
